# 上游许可资源

此目录只保存第三方许可原文和 attribution，不包含微信 DLL、用户数据或应用代码。
`UPSTREAM_MANIFEST.json` 列出 Qt 6.12.0 官方仓库的不可变提交、下载 URL 与逐文件 SHA-256。
Qt Base、Qt Image Formats 和 PySide/ Shiboken 的许可证及第三方声明按原目录保留。
其中有些资源用于未随本应用打包的 Qt 模块；保留完整声明方便发行审阅，不表示使用了这些模块。

Windows 构建必须核对清单版本与 PySide6 Essentials 版本，并校验每个资源摘要。
本目录的文件分别遵循所列许可，不受项目自有代码的 MIT 许可替代。
