# 支持范围与验证记录

当前为 Windows x64 预览版，兼容性依据已完成的验证声明，不保证全部微信 4.x 版本。

| 项目 | 状态 |
|---|---|
| Windows 11 x64 | 已构建目录包并通过冻结程序自检 |
| Windows 10 x64 | 尚待实机测试 |
| 微信 4.1.6.14 | 已验证取钥、联系人数据库校验、普通图片与 WXGF 导出及重复跳过 |
| 其他微信 4.x | 未验证，密钥布局或文件格式可能变化 |
| 普通图片 | JPEG、PNG、GIF、BMP、WebP，完整原文件保存并校验 |
| WXGF | 使用本机组件尝试生成静态图，原文件保留；动画和透明效果完整恢复未保证 |
| Windows ARM64 / x86 | 当前不支持 |
| macOS | 平台后端尚未实现，不发布 Mac 包 |
| 手机微信、企业微信 | 不支持 |

联系人名称以用户当前数据库记录为准，不承诺固定覆盖率。
V2 大文件解密按 `xor_size` 保留明文中段；仅通过文件头检测不能证明完整图片正确。

发行包自检使用人工构造的 PNG、DPAPI 和 spawn 工作进程，不代替真实客户端兼容性测试。
GitHub CI 不登录微信、不上传真实客户端数据。验证资料不得公开真实账号、名称、密钥、
来源路径、照片或个人数据数量；对外只保留系统、客户端版本、验证能力和结果。

稳定版仍需在无 Python 的干净 Windows 机器、不同用户及安装位置验证完整流程，
包括单群、多群、全部、取消恢复、无权限和磁盘不足。
签名、安装程序、自动更新及 macOS 后端尚未提供，不能按早期规划视为已支持。
