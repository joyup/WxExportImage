# 桌面版架构

```text
src/wechat_photo_export/
  core/       图片策略、解密、可信身份、SQLCipher/WAL、文件边界
  platforms/  Windows 进程读取、DPAPI、本机转换器及子进程
  services/   账号发现、名称目录、SQLite 状态、计划、导出、索引
  gui/        Qt Widgets 界面与后台工作线程
  cli.py      公共服务的命令行入口
packaging/    Windows 白名单冻结配置
tests/        人工构造的图片、加密页、界面及安全边界测试
tools/        构建和干净源码快照
.github/      CI、依赖更新及故障模板
```

GUI 和 CLI 调用同一服务，不调用编号脚本或解析 stdout。后台线程拥有独立 SQLite 连接，
通过结构化结果通知界面。GUI 默认不勾选，账号和会话身份明确后才允许预览。

账号 UID 由规范化账号目录派生，完整会话 hash、完整 fileId、版本构成文件身份。
目录以可信名称与 hash16 命名；公开源码快照与桌面脱敏诊断不包含个人名称表。
账号缓存与输出根目录均绑定账号，禁止重复名字导致跨会话或跨账号合并。

预览扫描不创建照片目录或取密钥。执行先复核目录归属和源文件状态，持有输出锁，
解密、格式校验、原子发布后提交 SQLite 清单。目标存在时只接纳相同内容，禁止覆盖不同文件。
取消在文件边界生效，重跑复核目标摘要，不依赖上次的百分比。
文件发布后、任务记录前崩溃，重跑会验证相同目标并补记清单。

联系人数据库每个加密页和已提交 WAL 帧均验证；解密副本留在内存中。
Windows 取钥与格式代码分开，公共核心不导入 Windows API。

原生转换在 spawn 子进程里执行，短生命周期、超时和崩溃恢复；主入口在加载 Qt 前调用
`multiprocessing.freeze_support()`。当前打包选 PyInstaller 目录版，便于检查依赖、保留动态库和
验证冻结状态的工作进程。发行版使用 PySide6 Essentials，构建依赖由版本锁固定。

macOS 平台尚未实现；公共图片、身份、计划与状态设计可复用，取钥、路径及转换须实机验证。
