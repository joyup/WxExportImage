# Windows 桌面工具

获取目录版 ZIP 后完整解压，双击 `WeChatPhotoExport.exe`。保留 `_internal` 和 `licenses` 目录，
不需要另外安装 Python。当前包未签名；校对发布页提供的 SHA-256。应用不会自动提权。

使用步骤：

1. 登录 Windows 微信 4.x，确保想导出的原图已经在本机下载。
2. 在工具中明确选择账号。未发现账号时，选择其下含 `msg/attach` 的账号目录。
3. 点击“刷新群名 / 用户名”，从只读校验的联系人数据库获取名称。
4. 搜索并勾选一个或多个群，或点击“勾选全部会话”。全部包含单聊和未识别会话。
5. 选择保存目录，点击“预览导出”查看照片数和源文件大小，再点击“开始导出 / 继续”。
6. 处理中可以取消。重新预览并导出会核对已完成照片，跳过内容未变的文件，重试失败和待转换项。
7. 完成后打开保存目录或照片索引。

筛选或排序不会改变勾选的会话身份；搜索隐藏的已选项仍会导出，计数会提醒。
同名群按编号区分。没有名称时使用“会话__编号”，可选中一行人工确认名称。
选中会话行后点击“预览当前会话照片”，可查看少量高清样本；预览只存在内存，不生成缩略图文件。
人工名称优先于数据库名称。已创建目录按身份复用，修改显示名不会自动搬动旧文件。

仅 `_h` 高清版和 `_W` 大图版参与导出，同一完整 fileId 优先 `_h`。
普通版和缩略图不会导出。转换遇到私有 WXGF 时保留原文件，并尝试生成静态图片；
原文件不计为成功照片。转换失败可重试；动画和透明效果当前不保证完整恢复。
源文件超过 128 MiB 或解压尺寸异常时返回错误。

默认保存位置为用户“图片/微信照片导出/账号编号”。一个输出目录绑定一个账号，避免多账号混淆。
首次请选空目录或新的子目录。旧脚本已有照片不会被桌面版自动接管、删除或批量替换。
预览中的容量是加密源文件大小，私有格式转换后体积可能增加。

图片密钥和名称缓存位于 `%LOCALAPPDATA%\WeChatPhotoExport\accounts`，按账号隔离。
密钥缓存经 DPAPI 保护，并在使用时验证；没有必要每次启动重新扫描。
数据库密钥不持久化。所有照片、索引、名称和任务记录都只保存在本机。

常见错误：

| 错误码 | 处理 |
|---|---|
| `wechat_not_running` | 登录微信，再刷新名称或导出 |
| `image_key_unavailable` | 在微信打开 2–3 张原图，再导出 |
| `contact_key_unavailable` | 按编号导出或稍后刷新；已有名称保留 |
| `output_owned` | 选择新的目录；其他账号和旧脚本的数据保持原状 |
| `target_conflict` | 目标已有不同内容，保留现有文件，选择新目录 |
| `decoder_unavailable` / `decode_failed` | WXGF 已保存，确认本机微信安装后重试 |
| `source_changed` | 图片被清理或改动，重新预览 |
| `disk_full` | 释放空间后重新预览继续 |

若需反馈问题，点击“导出脱敏诊断”，只分享该报告和人工复现步骤。
不要上传图片、微信数据库、密钥缓存、本地状态库或显示真实会话的截图。
公共 CLI 的列表输出包含本机账号路径、名称和会话编号，也不能直接作为公开附件。

开发者可用公共 CLI，必须明确账号和范围，默认只预览。
以下账号、路径和名称均为占位示例：

```powershell
wechat-photo-cli accounts
wechat-photo-cli sessions --account "X:/xwechat_files/示例账号" --refresh
wechat-photo-cli export --account "X:/xwechat_files/示例账号" --output "X:/Photos" --group "示例群"
wechat-photo-cli export --account "X:/xwechat_files/示例账号" --output "X:/Photos" --all --apply
```
