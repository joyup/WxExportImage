# 微信照片导出

使用项目的公共 CLI 操作本机照片。
技能依赖已安装的 `wechat-photo-export` Python 包及 Windows 后端；安装与环境配置见
[项目 README](../../../README.md)。支持的系统、客户端和 WXGF 限制见[兼容性](../../../docs/兼容性.md)。

## 选择入口和范围

命令入口为 `wechat-photo-cli`。在源码工作区中，先定位本文件向上三级的项目根目录，
从该目录运行相对路径命令，优先使用项目虚拟环境：

```powershell
.venv/Scripts/python.exe -m wechat_photo_export --cli --help
```

下面用 `wechat-photo-cli` 表示该入口；也可用上述 Python 模块命令替换。
从用户请求和已确认的上下文确定账号、输出目录及会话范围。需要发现账号时运行 `accounts`，
多个账号不能自动取第一项。只询问尚缺的必要参数，沿用已经确认的选择。

用户明确请求把所选范围导出到已指定的目录，即已授权该次写入，不额外重复索要批准。
若请求仅预览，则不加 `--apply`。群名缺失、重名或编号无法唯一匹配时先解决选择问题，
不自动改为全部导出或换账号。只有请求明确包含全部会话时才使用 `--all`。

## 名称、预览与执行

以下路径和名称均为占位示例，执行前替换为本次已确认的值：

```powershell
wechat-photo-cli accounts
wechat-photo-cli sessions --account "X:/xwechat_files/示例账号"
wechat-photo-cli sessions --account "X:/xwechat_files/示例账号" --refresh
wechat-photo-cli export --account "X:/xwechat_files/示例账号" --output "X:/Photos" --group "示例群"
wechat-photo-cli export --account "X:/xwechat_files/示例账号" --output "X:/Photos" --group "示例群" --apply
```

会话列表读取本地缓存；需要更新名称时再加 `--refresh`，此操作需要微信运行。
名称来自人工确认或经过数据库认证的记录，不从聊天文本和窗口附近字符串猜测。
未命名或重名会话使用列表中的完整会话 hash 配合 `--session` 选择。
同一种选择参数可以重复提供；`--group`、`--session` 和 `--all` 不能混用。

先运行不带 `--apply` 的导出命令，核对账号、会话数、照片数和来源容量。
预览错误时停止该流程；核对通过后，按用户已经授权的同一范围执行。
预览不会取图片密钥或创建照片目录，但可能初始化本地账号状态。
让应用负责密钥校验和缓存，导出不需要打开或打印 `data/keys.json`。

## 结果与继续

只导出 `_h` / `_W`，同一完整 fileId 选最高版本，普通版和缩略图不补作原图。
当前没有高清文件时，可在微信尝试打开或下载原图，再重新预览；不能恢复本机不存在的照片。

取消或失败后，以同一账号、范围和输出目录重新预览并执行，应用会校验已完成文件再跳过。
保留目标冲突文件，报告冲突；不要为使任务完成而删除、覆盖用户既有文件或扩大范围。
WXGF 原文件保留，转换未完成时报告待转换数量，不能仅因原文件已落盘就宣称照片全部导出成功。

完成时报告成功、跳过、失败和待转换数量及输出位置。必要时使用
[桌面工具](../../../docs/桌面工具使用.md)的照片预览、人工确认名称和脱敏诊断。
公开 CLI 与桌面版共享账号状态；旧编号脚本的 JSON 名称表和导出映射不自动导入。
账号列表、会话列表及输出索引可能含个人路径或名称，不当作可公开的诊断材料。
隐私边界见[安全说明](../../../SECURITY.md)。
